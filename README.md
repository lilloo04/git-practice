# Git Practice

오픈소스 과제 레포지토리


## Purpose

This repository contains simple examples and notes for learning version control.

## Contents

- `README.md`: Project introduction
- `.gitignore`: Files excluded from version control
- `git-notes.md`: Basic Git command notes
- `hello.py`: A simple Python example
- `CONTRIBUTING.md`: Contribution guidelines

## Run the Example

Run the following command in an environment with Python installed:

```bash
python hello.py
```

## Learning Goals
- Understand repositories and commits
- Write clear commit messages
- Use a .gitignore file
- Practice pushing changes to GitHub
